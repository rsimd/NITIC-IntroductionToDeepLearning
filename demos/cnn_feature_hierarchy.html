CNN: conv と pooling を重ねたときの特徴抽象化

浅い層では局所的なエッジ，深い層では部品や全体構造に近い抽象的な特徴を扱う

特徴の流れ

conv は特徴を検出し，pooling は位置とサイズを粗くまとめる
input image
32×32×3
画素値そのもの。まだ意味のある特徴には分解されていない。
conv 1
30×30×8
小さな3×3領域から，縦線・横線・角・色の変化のような局所特徴を検出する。
pool 1
15×15×8
近い場所の反応をまとめ，少し位置がずれても同じ特徴として扱いやすくする。
conv 2
13×13×16
浅い特徴を組み合わせて，花びらの端・模様・部品のような広い特徴を作る。
pool 2 → classifier
6×6×16 → class
空間サイズを小さくし，最後は全体構造からクラスを判断する。
浅い層画素に近い情報を使い，エッジや色の変化に反応する。
中間層エッジを組み合わせ，局所的な形や模様を表す。
深い層部品や全体配置に近い抽象的な特徴を表す。
